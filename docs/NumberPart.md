# NumberPart

Which part of a number a field prints: the whole number (`all`), only the part before the decimal point (`whole`), or only the decimal places (`decimals`).

## Enum

* `ALL` (value: `'all'`)

* `WHOLE` (value: `'whole'`)

* `DECIMALS` (value: `'decimals'`)

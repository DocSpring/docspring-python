# TemplateType

The kind of template: `pdf` (fields placed on an uploaded PDF), `html` (a PDF rendered from HTML) or `docx` (a Word document with tags where the data goes).

## Enum

* `PDF` (value: `'pdf'`)

* `HTML` (value: `'html'`)

* `DOCX` (value: `'docx'`)

* `PAGE_DESIGNER` (value: `'page_designer'`)

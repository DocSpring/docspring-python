# OutputFormat

A file format DocSpring makes: `pdf`, `docx` (a Word document), `odt` (an OpenDocument file), or `png` (images of a PDF's pages).

## Enum

* `PDF` (value: `'pdf'`)

* `DOCX` (value: `'docx'`)

* `ODT` (value: `'odt'`)

* `PNG` (value: `'png'`)

# FieldReimportState

Whether a template's fields are being re-imported from its PDF.

## Enum

* `NONE` (value: `'none'`)

* `REQUESTED` (value: `'requested'`)

* `IMPORTED` (value: `'imported'`)

* `NO_FIELDS` (value: `'no_fields'`)
